# Bezpieczeństwo

Znalazłeś lukę, na przykład wyciek sekretów do bazy albo do lekcji? Nie zakładaj publicznego issue. Zgłoś to prywatnie przez [Security Advisories](https://github.com/NikodemJachec99/Programming-learner-MODE/security/advisories/new).

Found a vulnerability? Please report it privately through Security Advisories instead of a public issue.
